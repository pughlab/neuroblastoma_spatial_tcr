# Data

The initial `.h5ad` file is not included in this repository because it contains controlled-access patient-derived spatial transcriptomics data that will soon be included in another manuscript. The file is available from the authors upon reasonable request.

To support reproducibility, this directory contains processed `.csv` files generated by the analysis notebooks under `data/processed/`. These `.csv` files are the direct inputs used to regenerate the manuscript figures and source data tables.
